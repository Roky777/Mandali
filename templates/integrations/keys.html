Send your first order

Products and plans are matched by the code set in the catalog. Totals and taxes are calculated by Mandali. Resending the same order is safe: its external_id makes it idempotent.

curl {{ base_url }}/api/v1/orders \
  -H "Authorization: Bearer mdl_..." \
  -H "Content-Type: application/json" \
  -d '{"external_id": "order-1001",
       "customer": {"external_id": "cust-42", "name": "Asha Traders", "email": "asha@example.com"},
       "lines": [{"product": "retainer", "quantity": 1}]}'

The full reference, including customers, subscriptions, errors, and webhooks, is in docs/INTEGRATIONS.md in the project repository.
